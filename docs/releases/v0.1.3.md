## Highlights / 更新

- Add automatic cgroup v1 support using socket-trace; cgroup v2 continues using cgroup-skb.
- 新增 cgroup v1 自动兼容；原有 Prometheus 指标、标签和 Grafana/n9e 查询保持兼容。
- Validate IPv4/IPv6 TCP/UDP, independent container attribution, lifecycle cleanup and real Docker daemon restart on Linux.
- Add tag-triggered release builds, downloadable binaries, an offline Docker image, Compose and SHA256 checksums.

## Install / 安装

Download `luna-ebpf_0.1.3_docker_amd64.tar.gz` and `docker-compose.yaml` into the same directory:

```sh
docker load -i luna-ebpf_0.1.3_docker_amd64.tar.gz
docker compose up -d
curl -fsS http://127.0.0.1:9808/metrics
```

The public offline image is tagged `luna-ebpf:0.1.3`; no image registry login or compiler is required. Public releases do not include private registry images or host evidence.

Linux amd64 and arm64 binary archives include config and license notices. The Docker archive is **amd64 only**. Verify downloads with `sha256sum -c SHA256SUMS` after downloading the listed assets.

## Validation and limits / 验证与限制

Tested on Rocky Linux 9.7, kernel 5.14 and Docker 29.5.2, booted separately into genuine cgroup v1 and v2. Host, bridge, custom bridge, shared netns and same-host macvlan/ipvlan traffic passed. Compose, systemd and monitoring checks passed. Linux unit/race/vet and cross-builds passed; **arm64 runtime has not been tested**.

**v1 requires readable kernel BTF and supported kprobes. Older kernels without BTF are unsupported.** IPv4/IPv6 TCP/UDP are the validated MVP; RAW/ICMP completeness, forwarding/tunnels, cross-host overlay and production-scale high-PPS operation are not guaranteed. Packet counts can differ between backends because their observation points differ.

需要宿主 Docker Socket、PID/cgroup 视图及 BPF 权限。默认 Compose 使用 privileged，会授予广泛宿主权限；上线前请阅读仓库部署说明和验证范围。升级会重启 agent，累计计数重置，Prometheus `rate()` 会处理 Counter reset。
